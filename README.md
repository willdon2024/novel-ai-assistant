# 天才小说家 - AI小说创作助手

一个基于Moonshot AI的小说创作辅助工具，能够根据小说标题自动生成故事背景、情节线索和人物关系。

## 功能特点

- 🎨 现代化UI设计
- 🚀 快速生成故事框架
- 📝 生成详细的故事背景
- 👥 规划人物关系
- 📈 设计情节线索

## 安装使用

1. 克隆仓库：
```bash
git clone https://github.com/你的用户名/天才小说家.git
cd 天才小说家
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 设置环境变量：
```bash
export MOONSHOT_API_KEY='你的Moonshot API密钥'
```

4. 运行应用：
```bash
python app.py
```

5. 在浏览器中访问：
```
http://localhost:5000
```

## 技术栈

- 后端：Flask
- 前端：HTML5 + Tailwind CSS
- AI：Moonshot API

## 使用说明

1. 在输入框中输入你想创作的小说标题
2. 点击"生成故事框架"按钮
3. 等待AI生成结果
4. 查看生成的故事背景、情节线索和人物关系

## 注意事项

- 使用前请确保已设置正确的Moonshot API密钥
- API调用可能需要一定时间，请耐心等待
- 生成的内容仅供参考，建议根据实际需求进行调整和修改
